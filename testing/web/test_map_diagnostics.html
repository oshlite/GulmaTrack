📋 Troubleshooting Checklist

  • Buka page di browser
  • Buka DevTools (F12)
  • Lihat console logs (harus ada dengan emoji prefix)
  • Run test di atas untuk setiap component
  • Cek Network tab untuk /api/wilayah/data request
  • Verify response status harus 200
  • Verify response body adalah valid JSON
  • Cek database connection dengan artisan tinker
  • Verify GeoJSON files exist di datala/ folder
  • Jika semua OK tapi map belum muncul, share console logs
